# Domain Feedback

Use this repository to report bugs, request features, and ask questions about the Domain territory protection plugin.

Before opening an issue, search existing reports for the same problem. For bug reports, include the Domain version, Minecraft and server version, relevant configuration, steps to reproduce, and useful log output. Remove passwords, access tokens, and other private information from logs and configuration before posting.

Domain source code: https://github.com/BronzWarq/domain
