# Domain Feedback

This repository is the place to report bugs, suggest features, and ask questions about Domain.

Domain is a territory protection and land management plugin for Paper servers. It provides configurable territory flags, access controls, GUI management, and optional integrations with plugins such as Vault, WorldGuard, Dynmap, PlaceholderAPI, and Myriad.

Source code: https://github.com/BronzWarq/domain

## Before opening an issue

- Search existing issues to see whether the problem or suggestion has already been reported.
- Use the Bug Report template for problems and the Feature Request template for suggestions.
- Keep one issue focused on one problem or request.

## Reporting a bug

Please include as much of the following information as possible:

- Domain version
- Minecraft and server software versions, including the Paper build
- Java version
- The affected Domain block or territory type
- Relevant flags, access settings, and configuration sections
- Versions of related plugins and whether their integrations are enabled
- Whether the affected player is the owner, a member, or staff using bypass mode
- Steps to reproduce the problem
- What you expected to happen and what happened instead
- Relevant server logs or error messages

For territory protection issues, include the world and approximate location if it is safe to share. Describe the action that was blocked or allowed, such as building, interacting with a container, or entering a territory.

## Suggesting a feature

Describe the problem you are trying to solve, the feature you have in mind, and how it should behave for players or administrators.

## Privacy

Remove passwords, access tokens, personal information, and private server details before posting logs or configuration. Avoid sharing exact coordinates or other information that could expose a private server. Do not upload complete server directories or unrelated files.
